# microsteps-ai

## Problem

Starting tasks is often the hardest part.

## Solution

A CLI tool that generates minimal first steps using LLMs.

## Example

Input:
"I need to write a report"

Output:
Step 1: Open your editor and write one sentence starting with "This report is about..."

## Tech

- Python
- Ollama

## What I learned

- Simpler outputs → better action
- Highlighting "Step 1" improves usability
